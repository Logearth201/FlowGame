# Lumina Flow（ルミナ・フロウ）

好きな曲が、そのまま光の譜面になる。
イルミネーションの世界を、音に合わせて駆け抜ける音ゲーのプロトタイプです。

`index.html` 1ファイルで動きます（ビルド不要・外部ライブラリなし）。
同梱の実曲（`audio/`）を読み込むには、ローカルサーバー経由で開いてください。

```sh
npx http-server -p 8080   # → http://localhost:8080/
```

## あそびかた

ノーツが主人公の足もとの**光の輪**に重なった瞬間が操作のタイミングです。

| ノーツ | 見た目 | 操作 |
| --- | --- | --- |
| 光の玉 | 水色の玉 | 輪に重なった瞬間に、その玉のレーンを **タップ** |
| 双子星・三つ星 | 2〜3つのレーンに **同時に** 来て、光の線でつながる（○━━○、○━○━○） | 指を2〜3本使って **同時にタップ**（三つ星は Pro のみ） |
| 光の帯（ロングノーツ） | 金色の始点から、道の上に **光の道** がのびる | 始点をタップして **押したまま** 光の道をなぞる。道が曲がったら指をすべらせてついていく。離すタイミングの判定はなし |
| 流れ星 | 大きな黄緑の **矢じり** と彗星の尾。レーン全体が黄緑に照らされ、道にも矢印が描かれる | タップして、そのまま矢印の向きに **フリック**（↑ ← →）。はじかずに離すと MISS |

- 光の帯が近づくと、足もとにそのレーンの金色の目印と「›››」の矢印が出る
- 押した瞬間がタップ判定。流れ星の上で押したときは、そのあとの指の動きをフリックとして判定する
- 光の道の途中の点は、そのレーンを押さえている指（またはキー）があれば取れる。早く離すと残りは MISS
- 光の道のスコアは始点と途中の点ごとに入るが、**コンボは最後まで取りきって1つ**。途中で1つでも落とすとコンボが切れる
- **ノーツ音**：タップ・同時押し・流れ星・光の道の始点と途中で、それぞれ違う短い効果音が鳴る（メニューでオフにできる）。ノーツがないところを押しても小さく鳴る
- 判定：±50ms BRILLIANT / ±100ms GREAT / ±160ms GOOD。満点は1,000,000点
- キーボード：3レーンは `J` `K` `L`、4レーンは `D` `F` `J` `K`、5レーンは `D` `F` `Space` `J` `K`（見た目の左から順、レーン数に合わせて自動で切り替わる）。流れ星はキーを押すだけで取れる。光の道はそのレーンのキーを押したままにし、道が曲がったら次のレーンのキーに持ちかえる。`Esc` でやめる
- ヒントをオンにすると、最初の数個のノーツに操作の案内が出る

### レーンの数（曲ごと・場面ごとに変わる）

レーンの数は選ぶものではなく、曲が持っています。4小節ごとの盛り上がり（音量と音の立ち上がりの多さ）を、その曲の中での順位で **3・4・5本** に分けます。

- 静かな場面は3本、盛り上がる場面は5本になる。短い場面はつなげて、最低8小節は続ける
- 曲全体の盛り上がりの差が小さい曲は、4本のまま
- 切り替わる1小節前に「レーンが5本にふえるよ」と予告が出る。奥から緑の光の線が近づき、そこを越えるとレーンの数が変わる
- 例：シャイニングスターは 3→4→5→3→4→5→4→5→3 本と変わる

### むずかしさ

| | 内容 |
| --- | --- |
| Easy | 拍の頭（4分音符）だけ。同時押しは少しだけ |
| Normal | 8分音符まで。流れ星が出はじめる |
| Hard | 8分音符が中心で、テンポがゆっくりな曲では16分音符も。同時押し・流れ星がふえる |
| Pro | 16分音符の連打、3つ同時押し（三つ星）、流れ星が多め |

## コースの動き（方向転換）

コースの動きはユーザーが選ぶものではなく、**曲と難易度で決まっています**。曲からは「どこで盛り上がるか」、難易度からは「どこまで動かすか」を決めます。

| | カーブ | 坂・丘 | 回転 |
| --- | --- | --- | --- |
| Easy | ゆるい | のぼり・くだりだけ | なし |
| Normal | ふつう | あり | サビで1回だけ 180° |
| Hard | 大きめ | あり | 180°・90° を最大3回 |
| Pro | いちばん大きい | あり | 90°・180° を最大6回、間隔も短い |

- **カーブ**：道が左右に曲がり、景色が横に流れる（向きが変わる）
- **坂**：サビの前で空へのぼり、静かになる前にくだる
- **回転**：盛り上がりで世界ごと回る。180° ではノーツが **下から上へ** 流れる。1小節前に予告が出る
- 回転中も、タップは光が見えている場所、キーボードは見た目の左右に合わせて反応する
- 端末で「視差効果を減らす（動きを減らす）」をオンにしていると、コースはまっすぐになる

## 自動譜面化のしくみ

読み込んだ曲は端末の中だけで解析します。

1. **音の立ち上がり**：FFT（1024点・約11.6ms刻み）で、低域・中域・高域ごとにスペクトルが急に増えた量を出す
2. **テンポと拍**：立ち上がりに等間隔の櫛を当てて 70〜210BPM を総当たり（音ゲーの曲は速いことが多いので、140BPM 付近を少し優先）。低音が一番強い拍を小節の頭にする
3. **リズム譜面**：拍のグリッド上で強い立ち上がりを、小節の盛り上がりに応じた数だけ選ぶ。特に強い表拍は同時押し（Pro では一番強いものを3つ同時に）、高域が主役の裏拍は光の帯、静かな小節は光の帯の流れにする。にぎやかな曲でも8小節に1回はドラッグの場面を作る。フレーズの終わり（次の音まで1拍近くあく音）は流れ星にする
4. **レーン**：音色の明るさ（スペクトル重心）の順位で、低い音は左、高い音は右。どのレーンにも同じくらい出るようにしている

## 歌の解析（PoC）

「譜面のつくり方」で **うたに合わせる** を選ぶと、歌の音符に合わせてノーツを置きます。

1. **歌を取り出す**：左右の差（サイド）が小さい成分だけを残すマスクで、中央に定位した音を取り出す。歌はふつう中央にある
2. **歌っている区間**：中央に集まったエネルギーの割合と、倍音のはっきりさが一定以上の時間を「歌っている」とみなす
3. **音の高さ**：D3〜D6 の候補ごとに倍音の重なりを足し、倍音の間の音を減点して、1オクターブ下の誤検出を防ぐ
4. **音符に区切る**：歌い始め、音の高さの変化、言葉の立ち上がりで区切る
5. **譜面**：歌の小節は、音符の頭に光の玉を置く。前後の音との高さの関係でレーンを選び、伸ばす音は同じレーンの光の帯にする
6. **歌詞**：貼り付けた歌詞の行を、行の文字数（≒音節数）と音符の数が合い、行の切れ目が歌の途切れに来るように動的計画法で割り当てる。プレイ中は画面下にカラオケ風に表示する

メニューの「曲の解析結果を見る」で、次の内容を時間軸で確認できます。

- スペクトル
- 音の立ち上がり
- 拍と小節
- 歌の区間と音の高さ
- 歌詞の位置
- 生成したノーツ

### 試した結果と、わかっている限界

- テンポ：合成曲5曲はすべて正しいBPMを推定した（誤差0.02以内、拍の位置のずれ約10ms）。シャイニングスターは 158 BPM と推定し、librosa の拍の間隔（約0.385秒）とも合う
- 歌の区間：シャイニングスターでは歌の割合が約56〜60%。間奏らしい区間（冒頭、1:20〜1:40ごろ、終盤）ははっきり下がる。歌のない合成曲は約10%
- 歌詞の割り当て：合成した歌声の曲では、12行のうち約半分が実際の位置から1.2秒以内に入った。合成の声が検出しにくい箇所があり、精度はまだ低い
- モノラル音源や、楽器も中央にある曲では、歌だけを取り出せない
- 歌詞の文字そのものの聞き取りはしていない。正確な歌詞の同期には、音声認識（Whisper など）か、学習済みの音源分離モデル（Demucs など）をサーバーや WebGPU で動かす必要がある
