# Lumina Flow（ルミナ・フロウ）

好きな曲が、そのまま光の譜面になる。
イルミネーションの遊歩道を、音に合わせて駆け抜ける音ゲーのプロトタイプです。

`index.html` をブラウザで開くだけで遊べます（ビルド不要・外部ライブラリなし）。

## 世界観

- 夜の遊歩道。地平線の向こうに街あかりのボケ、空にはオーロラ。
- 小節ごとに **光のアーチ（ルミナリエ）** が近づいてきて、くぐるたびに音楽が進んでいる感覚を出す。
- 拍ごとに路面を光の波紋が流れ、道の両脇のランプが灯る。
- 曲の盛り上がり（音量の包絡）に合わせて、空の色やライトの明るさが変わる。
- 主人公は「光の精」。拍に合わせて弾みながら、きらきらの軌跡を残して走る。

## ノーツと操作

| ノーツ | 見た目 | 操作 | 譜面での役割 |
| --- | --- | --- | --- |
| 光の玉 | 水色の光の玉 | **タップ**（画面の左・中・右＝3レーン） | 基本のリズム。キック・スネア・メロディの立ち上がり |
| 双子星 | ピンクの二つ並んだ光 | **ダブルタップ**（0.35秒以内に2回） | 曲の一番強い拍。サビの頭などのアクセント |
| 光の帯 | 金色の粒をつないだ線 | **主人公をドラッグ**して通り道に合わせる | 高音のきらめき、静かなパート |

キーボードでは `J` `K` `L` がタップ、`←` `→` で主人公の移動です。

判定は ±50ms で BRILLIANT、±100ms で GREAT、±160ms で GOOD です。

## 自動譜面化のしくみ

読み込んだ曲は端末の中だけで解析します（サーバーには送りません）。

1. **スペクトル解析**：曲をモノラル・約22kHzにして、1024点のFFTを約11.6msごとにかける。
2. **音の立ち上がり（オンセット）**：低域（〜200Hz）・中域（〜2kHz）・高域の3帯域で、スペクトルが急に増えた量（スペクトルフラックス）を出す。低域はキック、中域はスネアや声、高域はハイハットやベルのきらめきにだいたい対応する。
3. **テンポと拍の位置**：立ち上がりの強さに櫛形（等間隔）のフィルタを当て、70〜180BPMを総当たりして最も揃う周期と位相を選ぶ。低音が一番強い拍を小節の頭とみなす。
4. **ノーツを置く**：拍のグリッド（やさしい＝4分、ふつう＝8分、むずかしい＝16分）の各位置で立ち上がりの強さを測り、小節ごとに盛り上がりに応じた数だけ強い位置を選ぶ。表拍は少し優遇する。
5. **種類を決める**：特に強い表拍は「双子星」、高域が主役の裏拍は「光の帯」、それ以外は「光の玉」。ノーツが少ない静かな小節は「光の帯」の流れにして、主人公を動かす区間にする。
6. **レーンを決める**：音色の明るさ（スペクトル重心）で、低い音は左、高い音は右に置く。同じレーンが続きすぎないようにずらす。光の帯は2小節で一往復するゆるやかな曲線で、1拍に1レーン以上は動かさない。

## サンプル曲「星降る遊歩道」

著作権の心配がないように、ページを開くたびにその場で作曲・合成しています（120BPM、約1分27秒）。

- 進行：Fmaj7 → G6 → Em7 → Am9 のくり返し
- 構成：イントロ（ベルとパッド）→ A（キックとベース）→ B（メロディ）→ サビ（16分のアルペジオ）→ 静かなブリッジ → サビ → アウトロ
- 音色：パッド、ベル、キック、ハイハット、クラップ、ベース、リード、ライザー、ディレイとリバーブ

サンプル曲も自分の曲と同じ解析を通して譜面にしているので、自動譜面化がどう働くかをそのまま確かめられます。
